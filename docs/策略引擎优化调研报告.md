### 2.2 Monte Carlo模拟精度

**行业标准：**
- 10,000次 = 快速决策，±1%精度
- 30,000+次 = 精确分析
- 100,000+次 = 严肃研究（据devutl.com）

**当前系统：** mcVsRange 5000次
**问题：** 在接近50%equity的关键决策点，±1%误差可能导致错误判断

### 2.3 牌面结构分类

**行业细分（4档 vs 当前3档）：**

| 类型 | 特征 | 策略重点 |
|------|------|---------|
| Static/Dry | 无连接性，低牌面 (K72r) | 高c-bet率(60-80%) |
| Semi-Dynamic | 中等连接 (Q94r) | 平衡策略 |
| Dynamic/Wet | 高连接 (QJT9, 87s) | 防守+保护 |
| Paired | 对子面 (KKx, 88x) | 范围优势分析 |

**当前系统缺陷：** boardTexture()只返回0/1/2/3 wetness，缺少：
- 连接性分析（straight draw combos）
- 高牌面分析（Blackjack boards）
- 范围优势计算

### 2.4 位置处理

**行业最佳实践 vs 当前系统：**

| 指标 | 行业数据 | 当前系统 |
|------|---------|---------|
| BTN vs UTG EV差 | 20-30bb/100 | posMod: ±6 |
| IP equity调整 | +5-8% | +3% |

## 三、优化优先级矩阵

### P0级：影响巨大，改动可控

#### 1. 【翻前范围校准】
- **现状：** 开池范围普遍偏宽20-30%
- **行业：** GTO Wizard标准范围
- **收益：** 减少翻前EV损失，预计+2-5bb/100
- **改动：** 替换O6/O9范围表，约200行

#### 2. 【对手类型对翻前范围的影响】
- **现状：** 翻前范围不随对手类型调整
- **行业：** vs Nit可开更宽，vs LAG应收紧
- **收益：** 对手分类后EV提升约3-8bb/100
- **改动：** 在preF()中增加对手类型判断

```javascript
// 建议实现
function adjustPreflopRange(baseRange, oppType, scene) {
  if (oppType === 'nit') {
    // Nit开池弱，可扩大开池范围15%
    if (scene === 'open') return expandRange(baseRange, 0.15);
    // 面对nit 3bet应收紧
    if (scene === 'raise') return contractRange(baseRange, 0.10);
  }
  if (oppType === 'lag') {
    // vs LAG 收紧开池，3bet范围扩大做价值
    if (scene === 'open') return contractRange(baseRange, 0.10);
    if (scene === 'raise') return expandRange(baseRange, 0.15);
  }
  if (oppType === 'fish') {
    // 鱼开池范围宽，可用宽范围隔离
    if (scene === 'open') return expandRange(baseRange, 0.20);
  }
  return baseRange;
}
```

#### 3. 【Monte Carlo迭代次数优化】
- **现状：** 固定5000次
- **问题：** 在45-55%equity区间精度不足
- **方案：** 动态调整迭代次数
- **改动：** 20行代码

```javascript
function mcVsRange(hole, comm, oppRange, baseIter) {
  // 基础精度
  var baseIterations = baseIter || 5000;
  // 河牌阶段需要更高精度（不可重入）
  if (comm.filter(c => c).length === 5) {
    baseIterations = 20000;
  }
  // equity接近50%时增加迭代
  var equity = quickEquityEstimate(hole, comm, oppRange);
  if (Math.abs(equity - 50) < 15) {
    baseIterations = Math.round(baseIterations * 1.5);
  }
  return runSimulation(hole, comm, oppRange, baseIterations);
}
```

### P1级：收益较大，改动中等

#### 4. 【位置equity realization调整】
- **现状：** IP+3%, OOP-2%
- **行业：** realization差值约10-15%
- **方案：** 细化街道和场景的位置调整

```javascript
// 建议实现
function positionEquityAdjustment(pos, street, action) {
  var pa = pA(pos);
  var ip = pa >= 0.5;
  
  // 基础IP/OOP调整
  var baseAdj = ip ? 4 : -3;
  
  // 街道修正
  if (street === 'flop') baseAdj += ip ? 2 : -1;
  if (street === 'turn') baseAdj += ip ? 3 : -2;
  if (street === 'river') baseAdj += ip ? 4 : -3; // 位置价值在河牌最大化
  
  // 场景修正
  if (action === 'cbet') baseAdj += ip ? 2 : -1;  // IP cbet效率更高
  if (action === 'check') baseAdj += ip ? 1 : -2; // OOP check更被动
  
  return baseAdj;
}
```

#### 5. 【牌面结构精细化】
- **现状：** 干/中/湿 3档
- **行业：** 需要4-5档分类
- **改动：** 重写boardTexture()函数

```javascript
// 建议实现
function boardTexture(comm) {
  var c = comm.filter(card => card);
  if (c.length < 3) return {type: 'preflop', wetness: 0};
  
  var analysis = analyzeConnectivity(c);
  var analysis2 = analyzeSuitDistribution(c);
  var analysis3 = analyzeRankDistribution(c);
  
  // 分类
  if (analysis2.hasMonotone || analysis2.hasFlushDraw && analysis.hasHighConnectivity) {
    return {type: 'dynamic', wetness: 3, desc: '高动态面', 
            rangeAdv: analysis.rangeAdv, draws: analysis.straightCombos};
  }
  if (analysis.hasHighConnectivity && analysis.highCards > 2) {
    return {type: 'wet', wetness: 2, desc: '湿润面',
            rangeAdv: analysis.rangeAdv, draws: analysis.straightCombos};
  }
  if (analysis.hasPaired) {
    return {type: 'paired', wetness: 1, desc: '对子面',
            rangeAdv: analysis.rangeAdv};
  }
  if (analysis.lowConnectivity && analysis.highCards <= 1) {
    return {type: 'dry', wetness: 0, desc: '干燥面',
            rangeAdv: 'hero'}; // dry面对pre-flop raiser有利
  }
  return {type: 'static', wetness: 1, desc: '静态面', rangeAdv: 'neutral'};
}
```

#### 6. 【CBet频率按牌面调整】
- **现状：** 不区分牌面
- **行业：** 干燥面高c-bet，湿润面低c-bet

```javascript
// 建议实现
function cbetFrequency(texture, ip, oppType) {
  var base = ip ? 0.70 : 0.55; // IP略高
  
  if (texture.type === 'dry') {
    base += 0.10; // 干燥面可以更激进
    if (oppType === 'fish') base += 0.10;
    if (oppType === 'nit') base += 0.05;
  }
  if (texture.type === 'wet' || texture.type === 'dynamic') {
    base -= 0.15; // 湿润面需要更强的牌
    if (oppType === 'fish') base += 0.05; // 但vs鱼可以略宽
  }
  if (texture.type === 'paired') {
    base -= 0.05; // 对子面略降
  }
  
  return Math.max(0.3, Math.min(0.95, base));
}
```

#### 8. 【对手Tilt检测】
- **现状：** 无
- **行业：** PokerCharts等工具实现了tilt detection
- **指标：** 
  - 连续亏损后的行为突变
  - AF值异常飙升
  - 决策时间异常

```javascript
// 建议实现
var TiltDetector = {
  recentSessionWinnings: [],
  
  detectTilt: function(tracker, recentAction) {
    // 1. 连续bad beat检测
    var badBeats = this.countBadBeats(tracker.recentHands);
    if (badBeats >= 3) return {tilt: true, level: 'high', reason: 'bad_beats'};
    
    // 2. AF突变
    var afChange = tracker.recent_agg[tracker.recent_agg.length-1] - 
                   this.average(tracker.recent_agg.slice(0,-1));
    if (Math.abs(afChange) > 1.5) return {tilt: true, level: 'medium', reason: 'af_spike'};
    
    // 3. 近10手VPIP异常
    var recentVPIP = tracker.vpip / Math.max(tracker.hands, 1);
    var expectedVPIP = tracker.baseVPIP || 0.25;
    if (tracker.hands > 10 && Math.abs(recentVPIP - expectedVPIP) > 0.15) {
      return {tilt: true, level: 'low', reason: 'vpip_drift'};
    }
    
    return {tilt: false};
  },
  
  // 调整策略应对tilt玩家
  adjustForTilt: function(profile, tiltInfo) {
    if (!tiltInfo.tilt) return profile;
    
    if (tiltInfo.level === 'high') {
      // tilt严重，可能变疯，紧缩策略
      profile.adjustedType = 'tight';
      profile.foldMore = true;
    } else if (tiltInfo.level === 'medium') {
      // 略微激进，利用情绪
      profile.bluffMore = true;
      profile.valueThinner = true;
    }
    return profile;
  }
};
```

#### 9. 【反剥削逻辑】
- **现状：** 无
- **行业：** 高级RTA工具有"counter-exploit"模块
- **场景：** 对手可能在针对我们的调整

```javascript
// 简化实现
function counterExploitCheck(ourStrategy, oppProfile, street) {
  // 1. 检测是否被针对
  var isBeingExploited = detectExploitPattern(ourStrategy, oppProfile);
  
  if (!isBeingExploited) return null;
  
  // 2. 反制措施
  // 例如：对手知道我们紧，他开池很宽 → 我们可以3bet更多
  if (isBeingExploited.type === 'folding_too_much') {
    return {
      adjustment: 'wider_3bet',
      range: expandRange(ourStrategy.base3bet, 0.15),
      reasoning: '对手过度弃牌，可扩大3bet范围'
    };
  }
  
  return null;
}
```

#### 10. 【下注尺度精细化】
- **现状：** betSizingAdv()只基于equity
- **行业：** 需要考虑对手类型、牌面、街道

```javascript
// 建议实现
function betSizing(hole, comm, pot, oppType, texture, street, equity) {
  var sizing = {};
  
  // 基础尺寸
  var baseSize = equity > 70 ? 0.75 : equity > 50 ? 0.50 : 0.33;
  
  // 对手类型调整
  if (oppType === 'nit') {
    sizing.normal = Math.round(pot * 0.75); // 大尺度压榨
    sizing.bluff = Math.round(pot * 0.50);
  } else if (oppType === 'fish') {
    sizing.normal = Math.round(pot * 0.50); // 正常尺度
    sizing.bluff = Math.round(pot * 0.40);  // 鱼不太弃牌
  } else if (oppType === 'calling_station') {
    sizing.value = Math.round(pot * 0.80); // 超级价值
    sizing.bluff = 0; // 不bluff
  } else {
    sizing.normal = Math.round(pot * baseSize);
    sizing.bluff = Math.round(pot * baseSize * 0.6);
  }
  
  // 牌面调整
  if (texture.wetness >= 2) {
    sizing.normal = Math.round(sizing.normal * 1.2); // 湿面稍大
  }
  
  // 街道调整
  if (street === 'river') {
    sizing.normal = Math.round(sizing.normal * 0.8); // 河牌可以稍小
    sizing.bluff = Math.round(sizing.bluff * 0.7);
  }
  
  return sizing;
}
```
